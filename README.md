# EleevateOverseas Prototype

UX-first overseas education super-app prototype for the EleevateOverseas student and consultant journey.

## Live Prototype

After GitHub Pages deploys, the demo is available at:

https://abelg09.github.io/eleevate-overseas-prototype/

## Local Development

```bash
pnpm install
pnpm --filter @workspace/eleevate run dev
```

The frontend runs in demo mode by default so the product can be reviewed without connecting the final database.

## Build

```bash
pnpm --filter @workspace/eleevate run build
```
